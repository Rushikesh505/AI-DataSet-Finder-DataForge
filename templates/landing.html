Features

Everything a dataset needs.
Nothing it doesn't.

Built for ML researchers who need real, labeled data at scale.

Text

Focused article collection

Collects relevant text from pages and follows a limited number of internal links. Exports records in CSV, JSON, and JSONL formats.

  • Sentiment labels — POSITIVE / NEGATIVE / NEUTRAL
  • TF-IDF topic clustering with named labels
  • Relevance filter blocks off-topic pages
  • CSV, JSON, and JSONL export
Images

Context-aware image collection

Downloads images only when alt text + surrounding text + page title match your topic. No icons, no trackers, no garbage.

  • JPG, PNG, WEBP, GIF, BMP supported
  • Content-type verified before download
  • Size filter removes thumbnails under 5KB
  • Full image_dataset.csv + JSON metadata
Audio

Targeted audio collection

Searches Freesound.org and Archive.org, then checks candidate files against the selected topic.

  • MP3, WAV, OGG, FLAC, M4A, AAC
  • Relevance filter on filename + context
  • Content-type verified — no fake audio
  • audio_dataset.csv + JSON metadata
Video

Open video dataset collection

Searches Archive.org video archives and open repositories. Downloads MP4, WEBM, MOV with topic relevance checking.

  • MP4, WEBM, AVI, MOV, MKV supported
  • Archive.org deep integration
  • File size cap prevents runaway downloads
  • video_dataset.csv + JSON metadata
Target-GB Engine

Bounded collection runs

Choose a requested size and data type. DataForge searches within a time limit and packages available results when the run ends.

  • Parallel page discovery and media downloads
  • Run time countdown in the dashboard
  • Partial results are saved at the time limit
  • No fake progress — real byte counting
REST API

Programmatic access

Full REST API. Start jobs, poll status, stream logs, download results — all programmable. Build data pipelines that run automatically.

  • POST /api/start — launch any pipeline
  • GET /api/status/:id — real-time progress + logs
  • GET /api/download/:id — retrieve ZIP
  • Standard HTTP, JSON responses

# Start a 2GB text dataset job import requests, time r = requests.post('http://localhost:5000/api/start', json={ "topic": "crop disease detection agriculture", "mode": "text", "target_gb": 2.0, # run until 2GB collected "min_relevance": 0.35, # filter strength "num_clusters": 8, }) job_id = r.json()["job_id"] # Poll until complete while True: s = requests.get(f'/api/status/{job_id}').json() collected = s['collected_bytes'] / 1024**3 print(f"Progress: {collected:.2f}GB / 2GB") if s["status"] in ["done", "error"]: break if s.get("internet_exhausted"): print("Internet exhausted for this topic") break time.sleep(5) # Download the dataset data = requests.get(f'/api/download/{job_id}')
